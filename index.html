  • Portfolio 1: Penguin Species Visualizations
    Interactive species classification exploration using Vega-Lite configurations.

    This section features 1 basic scatter plot and 3 systematic variations built from the exact same underlying penguin data metrics (Culmen Length, Culmen Depth, and Species). Each chart manipulates structural marks, scales, and dimensional axes to shift how the biological insights are communicated.

    Chart 1: The Basic Plot (Standard Scatter Plot)

    Decision-Making Process & Communication: This plot establishes the baseline relationship between physical attributes across different categorical groups. A scatter plot was chosen because it cleanly tracks two continuous metrics simultaneously across a nominal category using color. It effectively communicates that while there is overlap in raw values, species cluster neatly into distinct visual territories based on their skeletal proportions.

    Variation 1: Faceted Grid & Zoomable Axis Scale

    Decision-Making Process & Communication: This variation addresses overplotting by utilizing small-multiples structural faceting, moving the categorical dimension from color encoding to a spatial split. The scale config maximizes screen real estate by wrapping strictly around the active coordinate window, and the added interval selection lets users zoom and scroll inside the grids. It shifts communication away from mixed group boundaries toward isolating internal distributions and density patterns within each standalone species.

    Variation 2: Swapped Dimensions & Color Map Heatmap

    Decision-Making Process & Communication: For this iteration, the position roles were intentionally re-prioritized. One numeric axis was completely swapped out for the categorical feature, while the displaced numeric metric was pushed onto a sequential color ramp (Viridis). Utilizing a high-thickness tick mark creates a barcode-style density visualization. It communicates comparative summaries much quicker than a scatter plot, allowing the viewer to immediately scan vertical density ranges while simultaneously tracing how long a penguin's bill grows along a uniform gradient.

    Variation 3: Binned Aggregation Matrix

    Decision-Making Process & Communication: This layout shifts focus away from granular individual observations to macro statistical aggregates. It divides both continuous fields into segmented boxes (bins) and encodes the statistical count using a high-contrast heatmap spectrum. Instead of relying on individual data coordinates to show species habits, it transforms the subset into structured matrix zones. This makes it significantly easier to communicate the single most common biological sweet-spot (highest frequency concentration) for each respective type.
