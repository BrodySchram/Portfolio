  • Portfolio 1: Penguin Species Visualizations
    Interactive species classification exploration using Vega-Lite configurations.

    This section features 1 basic scatter plot and 3 systematic variations built from the exact same underlying penguin data metrics. Each chart manipulates structural marks, scales, and dimensional axes to shift how the biological insights are communicated.

    Chart 1: The Basic Plot (Standard Scatter Plot)

    Decision-Making Process & Communication: This plot establishes the baseline relationship between physical attributes across different categorical groups. A scatter plot cleanly tracks two continuous metrics simultaneously across a nominal category using color.

    Variation 1: Faceted Grid & Zoomable Axis Scale

    Decision-Making Process & Communication: This variation addresses overplotting by utilizing small-multiples structural faceting, moving the species dimension from color encoding to separate charts. The zoom feature lets users scale into the grids directly.

    Variation 2: Swapped Dimensions & Color Map Heatmap

    Decision-Making Process & Communication: One numeric axis is swapped out for the categorical species feature, while the displaced metric is pushed onto a color ramp (Viridis) to create a clear density visualization.

    Variation 3: Binned Aggregation Matrix

    Decision-Making Process & Communication: This layout shifts focus away from individual coordinates to macro statistical aggregates. It divides the fields into grids and encodes sample count frequencies using a heatmap spectrum.
